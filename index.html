What the sliders really do

λ sets the tradeoff. In Combined mode, setting λ to zero leaves only the labeled answer. In KL-only mode, setting λ to zero switches off all updates. Increasing it makes changes away from the reference distribution more costly.

τ changes both distributions. Low temperatures concentrate mass on the largest logits; high temperatures expose more of the probability assigned to other tokens. Task cross-entropy always uses τ = 1.

τ² rescales the KL loss. It compensates for temperature-related gradient scaling. Temperature still changes the optimization problem.

Why Combined does not exactly copy the teacher

KL is a soft penalty, not an equality constraint. At an exact teacher–student match, the KL gradient is zero, but the task gradient can still move the student. The optimizer seeks a balance between the two gradients; KL need not decrease on every combined step.

For a simple exact example, set τ = 1. The combined optimum over this token distribution is q* = (one_hot(target) + λp) / (1 + λ). If the teacher assigns the target 20% and λ = 1, the optimum assigns it 60%. KL-only instead has its minimum at q = p, provided λ > 0.

A stationary point has zero total gradient, not necessarily zero loss. The task and KL gradients can cancel while both losses remain positive. The 500-step demo limit is not a convergence test.

The gradient equation above is for Combined. KL-only removes the task term, and SFT-only removes the KL term. These two teaching modes isolate the components; the paper uses their combination.

What does one step mean?

Each step recomputes the selected loss on the same prompt and target token, then updates the five student logits. It does not sample a new answer. Repetition reveals where each objective leads: KL-only approaches the teacher (with λ > 0), SFT-only approaches a one-hot target, and Combined approaches a gradient balance. Exact convergence is not guaranteed within 500 steps.

Real training also revisits examples across epochs, but it updates shared network weights over many contexts and token positions. This demo isolates one position so those competing objectives are easier to see.

What this toy model can show

This demo optimizes five logits at one token position. It shows how the two loss terms compete, including when the teacher assigns little probability to a new target. It does not model shared neural-network parameters, interference between facts, or measure hallucination rates. The synthetic example and trajectories are not experimental results from the paper.

The dashed comparison trains an independent student from the same initialization with λ = 0. Its curve is task cross-entropy; the solid total includes the KL penalty, so their heights represent different objectives.

THE MEMORY HOOK

Change the format. Add new facts. Keep old facts.

Those are three different outcomes. Attention-only separates the first from the second; training on known facts alone avoids introducing new facts.

Where does KL fit?

Self-distillation aims to learn new facts while limiting forgetting through an output-distribution penalty. These four freezing/data ablations do not use that penalty.
